# 小汪的日常

这是一个只在本机 `127.0.0.1:8765` 开放的个人网站。待办、规划、成功日记和心得保存在 `data/xiaowang.sqlite3`。不需要网络，也不需要安装第三方依赖。

## 启动

双击桌面的「小汪的日常.app」。如果网站已在运行，双击会直接打开网页；电脑重启后，双击会重新启动服务并打开网页。

备用方式：双击 `启动小汪的日常.command`，或运行 `python3 -B server.py`。备用方式会保留终端窗口；关闭窗口会停止服务。

网址：[http://127.0.0.1:8765](http://127.0.0.1:8765)

## 从 Git 仓库恢复

克隆仓库后，直接双击 `启动小汪的日常.command` 即可启动。首次使用时会自动创建 `data` 目录和本地 SQLite 数据库。

个人任务、规划、心得、日志和数据库备份都在 `data` 目录中；这个目录不会提交到 Git。迁移电脑时，请另行复制自己的 SQLite 备份。

如需重新生成 macOS 双击启动 App，请在项目目录运行：

```bash
osacompile -o "小汪的日常.app" launcher.applescript
```

生成的 App 要放在项目目录内使用。

## 分支待办

在「今日」页面先添加一件主任务，再点击任务右侧的「＋ 分支」，可以继续给任意分支添加下一层。每个步骤都能单独勾选；主任务旁会显示已完成的分支数量。勾选主任务会一起完成下面所有分支；取消勾选某一步会把它的上级任务恢复为未完成。

每日待办分为「工作」「生活」「个人学习」三栏。添加任务时可以选择分类，分支沿用主任务的分类；编辑主任务的分类时，下面的分支也会一起调整。

有计划日期的任务如果当天没有完成，会在之后每天对应的分类栏继续显示，并标出原定日期；完成后就不再延续。原计划日期不会被自动修改。

新建待办时可以设置截止日期（DDL），默认是当前选中的日期，也可以换日期或点日期框右侧的「×」不设截止。编辑主任务和分支时也可以调整或清空截止日期；截止当天或超过日期会在任务旁提示。旧待办不会自动补上截止日期。

例如工作任务「完成一个需求」可以拆为「需求澄清」「方案设计」「开发联调」「测试上线」；「方案设计」下面还可以细分「页面设计」和「接口设计」。

## 每日记录

「记录」页面按日期分为两部分：「成功日记」适合逐行记下当天做成的小事；「心得」保留自由书写、标题和标签。输入后自动保存，可以查看昨天或选择更早的日期。旧版心得会继续显示在「心得」中。

## 数据

- 页面右上角「备份数据」可下载 SQLite 数据库副本。
- 原始数据文件在 `data/xiaowang.sqlite3`。定期把此文件复制到安全位置。复制前建议退出服务；网页下载的备份可在运行时使用。
- 不要直接删除 `data` 目录。

本地网站不会自动在其他设备之间同步。这个启动程序中的项目路径指向当前工作目录；如果移动项目目录，需要重新生成桌面启动程序。
